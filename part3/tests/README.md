# Тесты третьей части

`run_tests.sh [all|fork_unnamed|fork_named|independent_shm|independent_mq|бинарник]` проверяет реализованные варианты.
По умолчанию (`all`) последовательно запускает четыре набора, бинарники берёт из
`build/bin/<вариант>/parking_<вариант>` относительно корня проекта.
Можно передать путь к бинарнику из другой сборки с обычным именем исполняемого файла.
Запуск возможен из любой рабочей директории.

Нужны Bash, AWK, Python 3.9+, `timeout`, C-компилятор, `/proc` и `/dev/shm`.

- `cases.txt`: 35 наборов, включая нулевые размеры, стратегии, нагрузку, лимиты,
  строгую проверку чисел и ошибку открытия журнала; ещё два сценария — SIGINT/SIGTERM.
- `check_log.awk`: состояния автомобилей, совместимость типов, единственность
  назначения места, размер очереди, число занятых мест и итоговая статистика.
- `check_processes.py`: 8 общих проверок дерева процессов, сигналов группе и до
  прибытия, параллельных запусков, seed, аварии ребёнка и испорченных журналов.
- `fail_syscalls.c`: библиотека LD_PRELOAD для ошибок инициализации и проверки
  жизненного цикла семафоров. Компилируется в /tmp, в рабочую программу не входит.

Для `fork_unnamed` выполняется ещё 12 проверок ошибок shm_open/ftruncate/
posix_fallocate/mmap/sem_init/fork и гибели ребёнка с захваченным state_lock.
Итого **57 проверок**.

Для `fork_named` выполняются 14 проверок ошибок (sem_open/sem_unlink вместо sem_init)
и ещё две проверки: полный жизненный цикл именованных семафоров без sem_init
и сохранение чужого объекта при ошибке O_EXCL. Проверяются флаги создания, права
0600, начальные значения, удаление имён и sem_close во всех процессах.
Итого **61 проверка**.

Проверяется отсутствие оставшихся детей и имён POSIX-памяти/семафоров.
Имена обоих вариантов удаляются до fork, поэтому при работающей модели тесты
проверяют отображения с отметкой `(deleted)` через /proc/PID/maps.
У именованного варианта также проверяются отдельные отображения семафоров.

При проверке ASan/UBSan задайте PARKING_SKIP_FAULTS=1: выполнятся по 45 проверок
без подмены системных вызовов. Проверки отката выполняйте на обычной сборке.
Последняя проверка обоих вариантов прошла внутри песочницы с detect_leaks=0,
так как LeakSanitizer несовместим с её ограничением ptrace. Это не проверка LSan.

Для independent_shm выполняются те же 37 сценариев через необязательный C-запускатель.
`check_independent.py` содержит 16 проверок ручного подключения, нулевого сеанса и независимости
процессов, разных cwd и порядка запуска, повторных номеров/генераторов/сеансов,
сигналов участникам и группе, параллельных сеансов, seed, аварии автомобиля,
ограниченного ожидания отсутствующего диспетчера и повреждённого отображения.
Ещё 12 проверок с LD_PRELOAD проверяют ошибки создания памяти/семaфоров,
posix_spawn, повтор удаления имени после ошибки и sem_close без sem_init.
Итого 65 проверок independent_shm и 183 для этих трёх вариантов.
ASan/UBSan без подмены системных вызовов выполняет 53 проверки independent_shm;
прогон прошёл с detect_leaks=0. Вспомогательные программы должны лежать рядом
с бинарником parking_independent_shm из проверяемой сборки.

Журналы сценариев сохраняются в part3/tests/logs/<вариант>/ (вне Git).
PARKING_TEST_LOGS задаёт другой каталог; при all это родительский каталог,
в котором создаются подкаталоги всех четырёх вариантов.
Дополнительные IPC-тесты создают библиотеку и журналы в /tmp и удаляют после проверки.
Для сборки библиотеки можно задать CC. Исходные тесты второй части — в part2/tests/.

Для independent_mq — **71 проверка**: 37 общих, 20 независимого запуска/протокола
и 14 с подменой системных вызовов. Дополнительно проверяются неверные атрибуты,
размер/версия сообщения, нагрузка при двух очередях ёмкостью 10, чужие объекты,
порядок адресованных ответов (check_mq_order.c), отсутствие shm_open/sem_init,
EAGAIN/EINTR и откат mq_open/mq_unlink. Наличие очередей проверяется через API,
поэтому /dev/mqueue может быть не смонтирована. Поддержка POSIX MQ ядром обязательна.
Все вспомогательные бинарники должны лежать рядом с запускателем проверяемой сборки.
Без LD_PRELOAD выполняется **57 проверок**; ASan/UBSan пройдены с detect_leaks=0.
Всего для четырёх вариантов — **254 проверки** обычной сборки.
