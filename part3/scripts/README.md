# Скрипты запуска третьей части

`run_fork_unnamed.sh [аргументы]` запускает `build/bin/fork_unnamed/parking_fork_unnamed`.
`run_fork_named.sh [аргументы]` запускает `build/bin/fork_named/parking_fork_named`.
Оба работают из любой директории и по умолчанию пишут журнал в `parking_result.txt`
в корне репозитория. Пользовательские флаги, включая `-L`, передаются программе.
Предварительно нужна сборка из корня: `cmake -S . -B build && cmake --build build`.

Оба варианта запускаются одним исполняемым файлом: родитель создаёт всех детей.
При одновременном запуске задавайте разные пути журналов через `-L`.

`run_independent_shm.sh [аргументы]` запускает C-программу `parking_independent_shm`,
которая создаёт уникальное имя сеанса, запускает внешние программы диспетчера
и генератора и ждёт их завершения. Генератор запускает внешние программы автомобилей.
Все участники также поддерживают ручной запуск из разных терминалов по имени сеанса;
диспетчер сам никого не создаёт. Цель parking_independent_shm собирает весь комплект.

`run_independent_mq.sh [аргументы]` аналогично запускает комплект из
`build/bin/independent_mq/`. Его цель CMake — parking_independent_mq. Для ручного
запуска используются parking_dispatcher, parking_arrivals и parking_car из этого
же каталога. Данные передаются через две POSIX-очереди сообщений, синхронизация —
через четыре именованных семафора.

CMake отвечает за сборку. Для демонстрации каждой из четырёх реализаций есть
отдельный скрипт. Подробные команды ручного запуска — в корневом readme.md.
