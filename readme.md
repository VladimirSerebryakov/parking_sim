# Симулятор автоматизированной парковки (ИДЗ №1)

## Требования к окружению
Для успешной сборки и запуска приложения потребуются:
*   ОС: Linux (WSL)
*   Компилятор: `gcc`
*   Системы сборки: `cmake` и `make`

## Инструкция по сборке

Выполните следующие команды в корневой директории проекта:

```bash
# 1. Создаем директорию для сборки и переходим в нее
mkdir build
cd build

# 2. Генерируем файлы сборки
cmake ..

# 3. Компилируем проект
make
```
В результате в директории `build` появится исполняемый файл `parking_sim`.

## Запуск программы

Вы можете запустить симуляцию с параметрами по умолчанию или гибко настроить их через аргументы командной строки.

### Базовый запуск
```bash
./parking_sim
```

### Запуск с пользовательскими параметрами
Программа поддерживает настройку всех ключевых переменных через флаги командной строки.

**Пример теста (много машин, мало мест, долгая стоянка):**
```bash
./parking_sim -t 200 -q 5 -r 1 -l 1 -s 0 -p 15 -P 30 -c 20
```

**Доступные аргументы:**
*   **Длительность симуляции:**
    *   `-t `: Предельное число тактов симуляции (по умолчанию: 100).
*   **Инфраструктура парковки:**
    *   `-q `: Максимальная вместимость очереди (по умолчанию: 3).
    *   `-r `: Количество мест для *Обычных* авто (по умолчанию: 2).
    *   `-l `: Количество мест для *Крупногабаритных* авто (по умолчанию: 1).
    *   `-s `: Количество мест для *Специальных* авто (по умолчанию: 1).
*   **Генерация трафика (пул автомобилей):**
    *   `-c `: Количество генерируемых *Обычных* авто (по умолчанию: 15).
    *   `-C `: Количество генерируемых *Крупногабаритных* авто (по умолчанию: 12).
    *   `-S `: Количество генерируемых *Специальных* авто (по умолчанию: 10).
*   **Поведенческие таймеры:**
    *   `-a ` / `-b `: Мин. и макс. интервал прибытия машин (по умолчанию: 1 и 2).
    *   `-p ` / `-P `: Мин. и макс. продолжительность стоянки (по умолчанию: 7 и 10).
    *   `-w `: Максимальное время ожидания машины в очереди до ухода (по умолчанию: 8).

## Взаимодействие и интерфейс

В процессе работы программа выводит на экран динамический текстовый дашборд.
*   **Альтернативный буфер:** Интерфейс отрисовывается в альтернативном буфере терминала, поэтому после завершения работы история ваших команд не будет засорена.
*   **Безопасное прерывание (Ctrl+C):** Программа корректно обрабатывает сигнал `SIGINT` (Ctrl+C). При прерывании программы программа сохраняет логи и выводит итоговую статистику.

## Логирование и результаты

После завершения симуляции в корневой папке будет сформирован файл **`parking_result.txt`**.
В нем содержится:
1.  Хронология всех событий (прибытие, парковка, уход, отказы).
2.  Итоговая статистика обслуженных и потерянных клиентов.

Для просмотра лога используйте утилиту `cat` или `less`:
```bash
cat parking_result.txt
```
